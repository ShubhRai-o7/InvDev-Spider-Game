STEPS TO REPRODUCE THE PROJECT IN UNITY

.Download the project as a .zip file from the repository and extract it into a single folder. 
.Install Unity Hub. 
.Open unity Hub, go to the add option and select the extracted folder from the file explorer drop-down. 
.The project will be displayed as a list in unity hub along with the required Unity version to open it.
